# Product Vision

## Objective

Create a premium immersive real-estate exploration and sales platform that connects visual discovery, inventory, client intent, sales workflows, and administration in one coherent product.

The platform must support public exploration and authenticated role-aware experiences without compromising the simplicity of the client journey.

## Core Spatial Hierarchy

```text
City
→ District / Community
→ Project
→ Project Experience
→ Building
→ Floor
→ Unit
```

## Primary Product Surfaces

1. Public / Client immersive experience
2. Authenticated Client personal journey
3. Sales Agent workspace within the immersive platform
4. Sales Manager supervisory experience
5. Admin operational/content management
6. Super Admin platform/system management

## Core Capabilities

- city and district exploration
- deep-zoom masterplans
- project hotspots and project previews
- multiple viewer technologies
- building/floor/unit exploration
- unit inventory and availability
- saved projects
- saved units
- project comparison
- unit comparison
- client interests
- recently viewed
- continue journey
- enquiries
- leads
- sales sessions
- shortlists
- team management
- content/inventory configuration
- analytics
- future CRM and enterprise integrations

## Experience Principle

The application should feel like:

```text
premium architectural visualization
+ spatial exploration
+ editorial storytelling
+ real-estate inventory intelligence
+ modern sales enablement
```

It must not feel like a generic SaaS dashboard.

## Delivery Levels

### Prototype
Prove navigation, viewer orchestration, responsive shell, mock API contracts, and core user journeys.

### MVP
Add persistent accounts, realistic inventory, client save/compare/interest, sales sessions, RBAC, analytics, production API integration, and operational reliability.

### Production Platform
Add hardened auth, server-side authorization, auditability, production observability, CMS/inventory integrations, CI/CD, data governance, security controls, performance budgets, and recovery procedures.

### Enterprise Scale
Only when justified: multi-organization tenancy, SSO/IdP, fine-grained policy management, regional deployment, data residency, centralized audit, integration governance, advanced feature flags, and formal SLOs.

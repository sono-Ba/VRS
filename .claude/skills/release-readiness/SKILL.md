# Release Readiness Skill

Review a feature/release across:

- product journey completeness
- UX/responsive behavior
- accessibility
- auth/RBAC
- API contracts
- error/loading/empty states
- type/lint/test/build status
- performance regressions
- telemetry/analytics needs
- security/privacy concerns
- rollback/recovery implications if production
- documentation drift

Classify unresolved issues as:

- Blocker
- High
- Medium
- Low

Do not require enterprise controls for a prototype unless the risk warrants them.

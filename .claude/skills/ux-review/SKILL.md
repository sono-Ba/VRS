# UX Review Skill

Review the current screen/flow as a Product Design Leader for a premium immersive real-estate platform.

Evaluate:

- clarity of hierarchy
- viewer dominance
- navigation/orientation
- breadcrumb placement/behavior
- guest vs authenticated friction
- role appropriateness
- mobile vs desktop interaction patterns
- touch targets
- accessibility
- motion restraint
- loading/error states
- visual consistency

Flag anything that feels like a generic dashboard or component library in the client immersive journey.

Recommend concrete improvements prioritized by user impact.
